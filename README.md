# 应用时间统一看板

把 **vivo X90（时光口袋）** 和 **iPad Air 6（屏幕时间）** 的 App 使用时长，统一汇总到一个网页看板：每天各 App 用了多久、打开几次、什么时刻用的，以及跨设备的总时长。

数据全部存在**你自己的 Cloudflare D1 数据库**里，不经过任何第三方。免费额度足够个人用。

---

## 手机上一键部署（无需电脑，约 5 分钟）

点下面的按钮，按提示注册 / 登录 Cloudflare，一路确认即可：

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/Monlknn/app-time-dashboard)

按钮会自动完成：
- 把这个项目复制到你的 GitHub 账号
- **创建一个 D1 数据库并绑定到 Worker**（你不用手动建库、也不用导入 SQL）
- 部署好看板，给你一个 `https://xxx.workers.dev` 的网址

> 表会在你第一次打开看板时**自动创建**，无需任何手动建表操作。

---

## 部署完成后

### 1. 打开看板
访问 Cloudflare 给你的 `https://xxx.workers.dev` 网址，能看到页面就成功了。

### 2. 设置同步令牌（可选但推荐）
在 Cloudflare → Workers 和 Pages → 你的 Worker → **设置 → 变量和机密** → 添加机密：
- 变量名：`SYNC_TOKEN`
- 变量值：自己编一串随机密码（比如 `MyBoard2026x9`）

设置后，所有上传数据的接口都需要带这串密码，别人即使知道网址也写不进你的库。
> 如果设了令牌，后面 Android 和 iPad 上报时都要带上它；不设则留空即可。

### 3. Android：安装自动同步版时光口袋
下载我给你的 `时光口袋-自动同步版.apk` 并安装，然后：
1. 打开 App → 我的口袋 → 备份与数据 → **自动同步看板**
2. 地址填：`https://你的域名/api/ingest/android`（如果设了令牌，末尾加 `?k=你的令牌`）
3. 点「立即同步」，看到「已上传 N 条」即成功。之后每 15 分钟自动同步。

详细步骤见仓库里的 [使用说明.md](使用说明.md)。

### 4. iPad：屏幕时间上报
用「快捷指令」建一个个人自动化，每天定时执行「获取 App 与网站活动」，把结果 POST 到：
`https://你的域名/api/ipad/daily`（带令牌时用 `?k=你的令牌`）

详细格式见 [使用说明.md](使用说明.md)。

## 数据口径

- **vivo X90**：来自时光口袋的精确使用片段（时刻、时长、次数都精确）
- **iPad Air 6**：来自系统屏幕时间的每日每 App 汇总（时长精确，无单次时刻/次数）
- 看板可切换「相加 / 去重」两种统计口径；所有时间按北京时间（GMT+8）

## 安全提醒

看板网址本身是公开的，但写入接口受 `SYNC_TOKEN` 保护。请务必设置一个令牌。
